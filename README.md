## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/charlesk513/Codveda.git
cd Codveda
```

Compile and run the individual Java projects using a Java Development Kit (JDK).

For database-based projects, configure the required database credentials and execute the provided SQL scripts where applicable.
